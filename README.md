# Kiosk Dashboard

HTML-дашборд для информационных киосков (информационных терминалов).

## Описание проекта

Одностраничное веб-приложение (SPA) для отображения данных в формате киоска. Приложение работает в браузере, имеет фиксированное разрешение 1920x1080, гибкую сеточную структуру с возможностью редактирования макета пользователем и визуальные индикаторы состояния системы.

## Технический стек

- **HTML5, CSS3, Vanilla JavaScript (ES6+)** - без фреймворков
- **Gridstack.js** - grid-layout и drag-n-drop виджетов
- **Chart.js** - визуализация графиков
- **FontAwesome Free** - иконки интерфейса
- **live-server** - dev-сервер с авто-обновлением

## Основные возможности

### Холст и сетка
- Фиксированное разрешение 1920x1080 (эмуляция экрана киоска)
- Настраиваемый шаг сетки (5px, 10px, 20px, 50px)
- Визуализация сетки только в режиме редактирования

### Режим редактирования
- Переключатель режима редактирования/просмотра
- Drag-and-drop виджетов с привязкой к сетке
- Изменение размеров виджетов
- Добавление новых виджетов через модальное окно
- Запрет наложения блоков друг на друга

### Виджеты
- Уникальный ID для каждого виджета
- Внутренняя микро-сетка для выравнивания контента
- Настраиваемые границы (толщина, цвет, стиль)
- Типы виджетов: текст, график, изображение, custom

### Управление данными
- Сохранение макета в JSON файл
- Загрузка макета из JSON файла
- Чтение данных из локального data/data.json

### Индикаторы состояния
- Глобальный статус (рамка вокруг холста):
  - 🟢 Зеленый: есть интернет ИЛИ данные обновлены недавно
  - 🔴 Красный (мигающий): нет интернета ИЛИ данные устарели
- Локальный статус для отдельных виджетов

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 8080, авто-обновление)
npm start
```

После запуска откройте в браузере: http://127.0.0.1:8080

## Использование

### Горячие клавиши
- `Ctrl+S` - сохранить макет
- `Ctrl+O` - загрузить макет

### Работа с виджетами
1. Включите режим редактирования переключателем в toolbar
2. Нажмите "Добавить блок" для создания нового виджета
3. Перетаскивайте виджеты мышью для изменения позиции
4. Используйте resize handles для изменения размеров
5. Выключите режим редактирования для фиксации макета

### Сохранение/загрузка макета
- Кнопка "Сохранить" скачивает JSON файл с конфигурацией
- Кнопка "Загрузить" применяет макет из JSON файла

## API

Приложение предоставляет глобальный объект `window.dashboardAPI` для внешнего управления:
- `setEditMode(enabled)` - включение/выключение режима редактирования
- `addWidget(config)` - добавление виджета программно
- `saveLayout()` - сохранение текущего макета
- `loadLayout(config)` - загрузка макета из объекта

## Требования к браузеру

- Современный браузер с поддержкой ES6+
- Разрешение экрана не менее 1920x1080 (рекомендуется)
- Работа в офлайн-режиме (без необходимости авторизации)
