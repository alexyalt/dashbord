# Идеи для улучшений (Ideas)

Этот файл содержит идеи для будущих улучшений и доработок проекта Kiosk Dashboard.

## Ближайшие улучшения (Short-term)

### UI/UX
- [ ] Добавить анимации при переключении режимов
- [ ] Улучшить визуализацию сетки (разные цвета для разных зон)
- [ ] Добавить tooltips к кнопкам toolbar
- [ ] Темная тема оформления
- [ ] Адаптация под разные разрешения экрана (масштабирование)

### Функционал виджетов
- [ ] Больше типов виджетов:
  - Таблицы данных
  - KPI-карточки с индикаторами трендов
  - Календарь/расписание
  - Видеопоток (RTSP/WebRTC)
  - RSS-лента новостей
- [ ] Настройка прозрачности фона виджета
- [ ] Группировка виджетов в табы
- [ ] Шаблоны виджетов для быстрого добавления

### Работа с данными
- [ ] Поддержка WebSocket для real-time обновлений
- [ ] REST API polling с настраиваемым интервалом
- [ ] Кэширование данных в localStorage
- [ ] Валидация структуры data.json
- [ ] Multiple data sources support

## Среднесрочные улучшения (Mid-term)

### Режим редактирования
- [ ] Выравнивание виджетов по линиям сетки (snap-to-grid)

- [ ] Отмена/повтор действий (Undo/Redo)
- [ ] Дублирование виджета
- [ ] Блокировка отдельных виджетов от перемещения
- [ ] Слои (layering) для виджетов

### Сохранение и загрузка
- [ ] Автосохранение в localStorage
- [ ] История версий макетов
- [ ] Экспорт в PNG/PDF
- [ ] Импорт из других форматов
- [ ] Синхронизация с облачным хранилищем

### Индикаторы состояния
- [ ] Настройка порога устаревания данных (N минут)
- [ ] Разные цвета для разных статусов (желтый - предупреждение)
- [ ] Звуковые уведомления при изменении статуса
- [ ] Лог событий статуса

### Производительность
- [ ] Оптимизация рендеринга при большом количестве виджетов
- [ ] Ленивая загрузка графиков

- [ ] Virtual scrolling для длинных списков

2. **Clock Widget** - часы с мировым временем
3. **Counter Widget** - счетчики с анимацией
4. **Gauge Widget** - спидометры/датчики
5. **Map Widget** - карты с метками (Leaflet/OpenStreetMap)
6. **Timeline Widget** - временная шкала событий
7. **Alert Widget** - список активных алертов
8. **Status Board** - таблица статусов систем
9. **Image Carousel** - слайдшоу изображений
10. **Markdown Widget** - рендеринг Markdown текста

- [ ] Отсутствие обработки ошибок при загрузке JSON
- [ ] Нет debounce для resize событий
